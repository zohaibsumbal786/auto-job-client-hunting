# AI Client Hunter Bot

Automated lead generation system for tech services (Web Dev, AI, ML, Data Science).

## Features
- Finds potential clients based on your services
- Generates personalized proposals
- Sends outreach emails
- Tracks leads and responses
- Email notifications for new opportunities

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Configure `.env` with your credentials
3. Run: `python main.py`

## Services Offered
- Web Development
- AI Solutions
- Machine Learning
- Data Science

## Contact
Email and contact details are automatically included in proposals.
